# Offload desk

Two people, four niches, one paper card. Claude writes a script from the brand files and the week’s brief. Remotion renders `OffloadCard`. A person posts by hand.

## Map

- `brand/` is what the model may say. `templates.md`, `assets.md`, and `brand/briefs/` are generated. Do not edit those by hand. `brand/motion.md` is the picture. `brand/sound.md` is the cue list. The script writer does not read either one.
- `web/` is the Offload Marketing desk. It opens on `/desk/home`: an overview of the loop (data in to data out), ideas, inspiration and numbers, after the logo intro (`web/public/intro/offload-intro.mp4`, rendered from the `Desk-intro` composition). The sidebar has four folding sections: Content generation loop, Brand (one tabbed page), Make (Library, Layouts, Inspiration, Ideas, LinkedIn) and Accounts. LinkedIn posts live in `web/research/linkedin.json`, and their voices in `brand/linkedin.md`. Pieces live in `web/data/desk.json`. Week research lives in `web/data/research.json` and `web/data/briefs.json`.
- `remotion/` is the picture. The schema is `remotion/src/template-schema.mjs`.
- `remotion/src/world/` is the dark kit: the launch films, one folder per film. `docs/video-pipeline.md` is how to make one. Colours are `remotion/src/tokens.ts` and the variables in `web/src/app/globals.css`.
- `remotion/assets/` is the only pose and prop folder. It is empty. There is no character to place.
- `scripts/generate-brand-docs.mjs` rewrites the generated files.
- `docs/library.md` is the template library: every format, its fields and its example films. Read it before opening any kit file. It is generated by `scripts/library.mjs`; do not edit it by hand. The desk shows it at /desk/library, with Inspiration (motion feeds, `web/research/inspiration.json`) and Ideas (`web/research/ideas.json`). Pulled pieces live in `web/research/pulled.json`.
- `docs/design.md` is the design of the desk and the picture. `docs/architecture.md` is how a week becomes a file, and the loop: inputs (Virlo, Signals, Research, our own numbers), then build, approve, post (Blotato), data back. `docs/outreach-rota.md` is the outreach officer's Day A / Day B rota across the 19 accounts. Keep these files current when a decision changes.
- `web/.env.local` holds secrets. It is gitignored.

## Commands

From `web/`:

```
npm run dev -- --hostname 127.0.0.1 --port 3000
```

Regenerate templates, assets, and this week’s briefs from the repo root:

```
node scripts/generate-brand-docs.mjs
```

Collect signals (outlier videos on the watch list) from the repo root:

```
tools/.venv/bin/python -I web/scripts/signals.py
```

Rebuild the template library, and read the inspiration feeds, from the repo root:

```
node scripts/library.mjs
python3 -I web/scripts/inspiration.py
```

Remotion studio, from `remotion/`:

```
npm run dev
```

Dark films studio, from `remotion/`:

```
npm run dev:world
```

## Conventions

Never hardcode colours. Use `tokens` in Remotion and the CSS variables `--paper`, `--ink`, `--blue`, `--stamp`, `--line`, `--quiet`, `--problem`, `--white`, `--night`, `--rule`, `--mark` in the desk. The values match. Change both together.

Never add a product claim that is not in `brand/product-facts.md`. Never name a pose or a prop that is not in `brand/assets.md`. Never put a number on a card that is not already in the week’s brief.

The writer reads `brand.md`, the niche file, `safety.md`, `platforms.md`, `product-facts.md`, `templates.md`, `assets.md`, and `brand/briefs/{niche}-{week}.md`. It does not read raw research. A film script also follows `brand/scripting.md` (who narrates each account, the shape, and the endings) and `brand/hook-styles.md` (which opening, rotated, and the rules for call-outs and jokes).
