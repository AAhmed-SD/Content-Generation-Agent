# WJEC Eduqas GCSE Geology C480QS: spec map

Every spec point of WJEC Eduqas Level 1/Level 2 GCSE (9-1) in Geology (C480QS), in the board's order, with the notes file that covers it.

- Specification: version 3, July 2026 (first teaching 2017, first award 2019). Qualification code C480QS (entry code C480P2); Ofqual number 603/0598/8. Not tiered.
- The content is organised in four Key Ideas, split into topics 1.1 to 4.2. Each topic lists lettered knowledge points (a, b, c ...) in one column and matching techniques and skills in a second column; both are examined. This map uses "1.3e" to mean topic 1.3, point (e); each file covers the point and its paired skills.
- Practical skills (Appendix B) and the required two days of fieldwork, including at least one directed investigation, are examined in both papers but not marked separately. They are covered in file 14, together with geological map skills used throughout Component 2.
- Existing notes elsewhere give background only: Earth's layers in [Astronomy 01 Planet Earth](../astronomy-edexcel/01-planet-earth.md), and the Moon and planets in [Astronomy 09](../astronomy-edexcel/09-exploring-the-moon.md) and [Astronomy 11](../astronomy-edexcel/11-exploring-the-solar-system.md). The geology points are covered in full here.
- `refs_checked: false`: references were taken from the version 3 spec PDF and still need a person to check them.
