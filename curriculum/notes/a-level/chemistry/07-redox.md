# Oxidation, reduction, oxidation states and redox equations

Redox reactions move electrons from one species to another. This file covers oxidation and reduction, oxidising and reducing agents, oxidation states, naming with Roman numerals, disproportionation, and building full redox equations from half-equations.

## 3.1.7 Oxidation, reduction and redox equations

*Refs: AQA 3.1.7 · Edexcel 3.1 to 3.13 · OCR A 2.1.5(a) to (f), 5.2.3(a) to (c) · OCR B ES(d) to (g), DM(c) · Eduqas C1.1(b), C1.6(c), PI1.1(a), (b), PI1.2(a), (b). Level: AS & A.*

### What you need to know

- Oxidation is the loss of electrons; reduction is the gain of electrons (OIL RIG).
- An oxidising agent accepts electrons (and is reduced); a reducing agent donates electrons (and is oxidised).
- Rules for working out oxidation states.
- Identify oxidation and reduction from changes in oxidation state.
- Write half-equations and combine them into a full redox equation.
- Use Roman numerals in names (iron(III) chloride, chlorate(I)).
- Disproportionation: the same element is both oxidised and reduced.

### Explained

**Oxidation state rules.**

1. An uncombined element is 0 (Na, O₂, Cl₂).
2. A simple ion has the oxidation state of its charge (Na⁺ +1, O²⁻ −2).
3. The oxidation states in a neutral compound add up to 0; in an ion they add up to the charge.
4. Fixed values: Group 1 +1, Group 2 +2, Al +3, F −1.
5. H is +1, except in metal hydrides such as NaH, where it is −1.
6. O is −2, except in peroxides (H₂O₂, −1), in OF₂ (+2) and in O₂ (0).
7. Cl is −1 except with O or F.

Examples:

| Species | Working | Oxidation state |
| --- | --- | --- |
| S in H₂SO₄ | 2(+1) + S + 4(−2) = 0 | +6 |
| Mn in MnO₄⁻ | Mn + 4(−2) = −1 | +7 |
| Cr in Cr₂O₇²⁻ | 2Cr + 7(−2) = −2 | +6 |
| N in NH₄⁺ | N + 4(+1) = +1 | −3 |
| Cl in ClO₃⁻ | Cl + 3(−2) = −1 | +5 |

**Roman numerals** give the oxidation state of the element that can vary: iron(II) sulfate FeSO₄, iron(III) oxide Fe₂O₃, sodium chlorate(I) NaClO, sodium chlorate(V) NaClO₃, potassium manganate(VII) KMnO₄, potassium dichromate(VI) K₂Cr₂O₇, sulfate(IV) is sulfite SO₃²⁻.

An increase in oxidation state is oxidation; a decrease is reduction.

**Writing half-equations in acid solution.**

1. Balance the element changing oxidation state.
2. Balance O by adding H₂O.
3. Balance H by adding H⁺.
4. Balance charge by adding electrons.

Example: MnO₄⁻ → Mn²⁺.

- Mn balanced.
- Add 4H₂O on the right: MnO₄⁻ → Mn²⁺ + 4H₂O.
- Add 8H⁺ on the left: MnO₄⁻ + 8H⁺ → Mn²⁺ + 4H₂O.
- Charge: left is +7, right is +2, so add 5e⁻ on the left: MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O.

Dichromate: Cr₂O₇²⁻ + 14H⁺ + 6e⁻ → 2Cr³⁺ + 7H₂O.

**Combining half-equations.** Multiply each so that the electrons are equal, add them, and cancel electrons and anything on both sides.

MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O
Fe²⁺ → Fe³⁺ + e⁻ (× 5)

MnO₄⁻ + 8H⁺ + 5Fe²⁺ → Mn²⁺ + 4H₂O + 5Fe³⁺

**Metals and acids (OCR A 2.1.5(e)).** Mg + 2HCl → MgCl₂ + H₂. Mg goes 0 → +2 (oxidised); H goes +1 → 0 (reduced). Ionic: Mg + 2H⁺ → Mg²⁺ + H₂.

**Disproportionation.** Chlorine with water: Cl₂ + H₂O ⇌ HCl + HClO. Cl goes from 0 to −1 (in HCl) and to +1 (in HClO). Chlorine with cold dilute sodium hydroxide: Cl₂ + 2NaOH → NaCl + NaClO + H₂O. Copper(I) in aqueous solution: 2Cu⁺ → Cu + Cu²⁺.

**Metals and non-metals (Edexcel 3.11, 3.12).** Metals generally lose electrons and are oxidised, forming positive ions; reactive metals are good reducing agents. Non-metals generally gain electrons and are reduced, forming negative ions; reactive non-metals such as fluorine and chlorine are good oxidising agents.

### Worked example

1. Write the half-equation for the reduction of SO₄²⁻ to H₂S in acid.

   SO₄²⁻ → H₂S. Add 4H₂O on the right. Add 10H⁺ on the left (8 for water, 2 for H₂S). Charge: left 10 − 2 = +8, right 0, so add 8e⁻. SO₄²⁻ + 10H⁺ + 8e⁻ → H₂S + 4H₂O.

2. Combine with the oxidation of iodide (2I⁻ → I₂ + 2e⁻).

   Multiply iodide by 4: 8I⁻ → 4I₂ + 8e⁻. Full: SO₄²⁻ + 10H⁺ + 8I⁻ → H₂S + 4I₂ + 4H₂O.

3. Identify the oxidising agent in 2Fe³⁺ + 2I⁻ → 2Fe²⁺ + I₂.

   Fe³⁺ gains electrons (reduced), so Fe³⁺ is the oxidising agent. I⁻ is the reducing agent.

### Common mistakes

- Saying the oxidising agent is oxidised. It is reduced.
- Putting electrons on the wrong side: reduction half-equations have electrons on the left.
- Forgetting to multiply to balance electrons before adding.
- Giving oxidation states as charges written like "2+" instead of "+2".
- Saying a disproportionation reaction has two different elements changing.

## Check questions

1. Define oxidation in terms of electrons and in terms of oxidation state. (2 marks)
2. Give the oxidation state of: (a) N in NO₃⁻, (b) S in S₂O₃²⁻, (c) V in VO₂⁺, (d) O in H₂O₂. (4 marks)
3. Name NaClO₃ and Fe₂(SO₄)₃ using Roman numerals. (2 marks)
4. Write a half-equation for the reduction of NO₃⁻ to NO in acid solution. (2 marks)
5. Combine the half-equations Cr₂O₇²⁻ + 14H⁺ + 6e⁻ → 2Cr³⁺ + 7H₂O and Fe²⁺ → Fe³⁺ + e⁻ into a full equation. (2 marks)
6. Explain, using oxidation states, why the reaction of chlorine with cold aqueous sodium hydroxide is a disproportionation. (3 marks)
7. In the reaction Zn + Cu²⁺ → Zn²⁺ + Cu, identify the reducing agent and explain. (2 marks)
8. Hydrogen peroxide can be reduced to water in acid. Write the half-equation. (1 mark)

8. H₂O₂ + 2H⁺ + 2e⁻ → 2H₂O (1).
