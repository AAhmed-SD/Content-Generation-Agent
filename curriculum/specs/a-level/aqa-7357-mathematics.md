## About this specification

Every spec point of the four boards, in each board's own order, with the notes file that covers it. All four specifications teach the same DfE subject content for A-level Mathematics, so each concept is written once.

- AQA 7357 uses the DfE content codes unchanged: overarching themes OT1 to OT3, then A (proof) to S (moments).
- Pearson Edexcel 9MA0 numbers Pure topics 1.1 to 10.5 (Papers 1 and 2), Statistics 1.1 to 5.3 and Mechanics 6.1 to 9.1 (both Paper 3). Because the numbers restart, the front matter of each file writes them as P (Pure), S (Statistics) and M (Mechanics), for example P2.1, S1.1, M6.1.
- OCR H240 (Mathematics A) uses lettered items 1.01a to 3.04c. Its Stage 1 column is shared with AS H230; Stage 2 is A-level only.
- OCR MEI H640 (Mathematics B) uses letter-and-number codes such as Mp1, Ma2, Mc19. The spec prints the leading M on the first row of each table only; here every code carries it. Tables headed (1) are shared with AS H630; tables headed (2) are A-level only.

Level key: AS & A = also in AS Mathematics; A-level only = not in AS; AS & A (part A-level only) = the AS course has the first part, and the rest is tagged (A-level only) in the notes.
