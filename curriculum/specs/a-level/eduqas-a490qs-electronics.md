## About this specification

Every spec point of WJEC Eduqas A level Electronics (A490QS), in the board's order, with the notes file that covers it.

- Specification: version 4, December 2025 (first teaching 2017, first award 2019). Ofqual number 603/0777/8.
- The content has four Core Concepts (examined in both papers), Component 1 topics 1 to 8 and Component 2 topics 1 to 8. Each topic lists lettered outcomes (a), (b) ... This map writes "CC2(d)" for Core Concept 2, outcome (d), "C1.3(h)" for Component 1, topic 3, outcome (h), and "C2.1(j)" for Component 2.
- Equations: the spec says which equations learners must "use" or "recall" and which they "select and apply" from the data booklet (Appendix A). Each file says which is which.
- AS: the Eduqas AS (a separate qualification, co-teachable) contains the Core Concepts, semiconductor components (except the p-n junction physics in C1.1(a) to (d)), logic systems, operational amplifiers, timing circuits, sequential logic outcomes (a) to (g), microcontroller flowcharts (C2.3(a)) and mains power supplies outcomes (a) to (d). These are marked "AS and A" below. The AS numbers its topics differently; the A-level numbering is used here.
- Component 3 (non-exam assessment, 20%) is two design-and-build tasks: a PIC microcontroller system in assembly language, and an integrated analogue and digital system. It is not examined content and is not covered by these notes, except that file 13 covers the assembly-language knowledge it needs.
- Existing notes at a lower level: [GCSE Electronics (Eduqas C490QS)](../../notes/gcse/smaller-stem/electronics-eduqas/map.md). Background physics: [A-level Physics 10](../../notes/a-level/physics/10-current-resistance-and-resistivity.md), [11](../../notes/a-level/physics/11-circuits-potential-dividers-and-emf.md) and [16](../../notes/a-level/physics/16-capacitance.md). Every A-level Electronics point is covered in full here.
