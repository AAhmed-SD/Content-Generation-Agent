## About this specification

Every spec point of the two boards, in each board's own order, with the notes file that covers it. Both specs follow the DfE GCSE Statistics subject content (2015), so the content is the same; the numbering is not.

- AQA 8382 (first teaching 2017, spec version 1.2). Content is numbered 3.1.1 to 3.5.36 in five sections (A to E), each point also carrying the DfE code (A1, B1a ... E13b), then 3.6 the Statistical Enquiry Cycle (3.6.1 to 3.6.5). Each point is set out in three columns: basic foundation, additional foundation and Higher content only. Two papers, 1 hour 45 minutes each, 80 marks each, tiered.
- Pearson Edexcel 1ST0 (Issue 2, December 2017; papers 1ST0/1F, 1ST0/1H, 1ST0/2F, 1ST0/2H). Content is coded topic, sub-topic letter, item number: 1a.01 to 3p.13. Higher-only content is in bold type and is listed only in the Higher tier table; items with no Foundation content are shown in the Foundation table as "Higher tier topic only". The statistical enquiry cycle is a separate numbered list of five stages (written SEC 1 to SEC 5 here). Two papers, 1 hour 30 minutes each, 80 marks each, tiered.

Tier key: F & H = on both tiers; F & H (part Higher only) = the point is on both tiers but part of it is Higher only (tagged (HT only) in the notes); Higher only = not on the Foundation tier.
