## About this specification

Every spec point of AQA GCSE Engineering (8852), in the board's order, with the notes file that covers it.

- Specification: GCSE Engineering, first teaching 2017, first exams 2019 (spec PDF dated January 2019). Linear, not tiered.
- Assessment: one written paper (60%, 120 marks) covering sections 3.1 to 3.6, and the non-exam assessment (NEA, 40%, 80 marks), a design-and-make task set by AQA. The NEA project itself is not covered by these notes; section 3.6 (practical engineering skills) is covered because the written paper can ask about it.
- Equation numbers E1 to E15 and maths skills M1 to M4 come from the spec's Appendix 1 (Mathematical understanding). Every equation is used in at least one worked example.
- `refs_checked: false`: references were taken from AQA's website subject-content pages and still need a person to check them against the spec PDF.
