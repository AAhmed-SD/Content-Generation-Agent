# Design references

DESIGN.md files from [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) (MIT, see LICENSE). They describe other companies' design systems.

They are for craft, not for copying. Offload's own look is `brand/motion.md`, `brand/identity.md` and the tokens. Use these to learn how good systems handle a problem, then solve it in Offload's palette and type.

| File | Read it for |
| --- | --- |
| `apple.md` | Glass surfaces, notifications, system-level UI that looks native |
| `cal.md` | Calendar layout, event blocks, scheduling UI |
| `notion.md` | Calm document UI, blocks, quiet type |
| `linear.app.md` | Dense, fast product UI and motion restraint |
| `superhuman.md` | Email UI, inbox rows, keyboard-first polish |
| `theverge.md`, `wired.md` | Editorial type, bold layouts, magazine energy |
| `oura.md` | Wellness tone, soft data visualisation |
| `raycast.md` | Command palettes, dark glass, crisp detail |
| `spotify.md` | Year-in-review style data stories |
